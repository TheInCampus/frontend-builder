# Local setup

## Requirements

- Node.js 20.9 or newer
- pnpm 12.6

## Install and run

From the repository root:

```sh
pnpm install
pnpm dev
```

The Next.js app runs at `http://localhost:3000`. Run `pnpm lint`,
`pnpm typecheck`, and `pnpm build` to validate the web workspace.

The API workspace is an architectural placeholder. No database, credentials,
environment variables, or backend service are required for the current demo.
